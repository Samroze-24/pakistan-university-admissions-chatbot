# PakUni Guide — Pakistan University Admissions Chatbot

> A chatbot that answers questions about university admissions in Pakistan —
> deadlines, merit, entry tests, fees, scholarships, programs, documents,
> hostels and eligibility — and calculates your merit in a short conversation.

Ask in English or Roman Urdu, e.g. *"mera merit kitna banega?"*, *"fee structure
for BSCS"*, *"scholarship mil sakti hai"*, or *"hostel available hai?"* — and the
bot replies from a curated knowledge base, or walks you through the merit
calculation step by step.

## Why this is different

Most chatbot demos are a few `if/else` replies on keywords. This one has three
real pieces, kept separate and honest:

- **Intent classification (ML).** A TF-IDF + LogisticRegression model trained on
  262 sample utterances decides what you are asking about (13 intents). Short,
  unambiguous messages (greetings, goodbyes, anything with the word "merit")
  are routed by a small deterministic keyword router first — a classifier is
  overkill for "hello", and unreliable on such short inputs with so little data.
- **Answer retrieval (TF-IDF cosine).** Replies come from a curated knowledge
  base of 30 Q&A pairs (`data/kb.json`). The bot never invents an answer: if
  nothing matches well enough it says so honestly and suggests questions it
  *can* answer. A low-confidence intent label is never trusted for a canned
  reply — the bot falls back to retrieval or the honest "I don't know".
- **Merit calculator (multi-turn slot filling).** For merit questions the bot
  asks for your Intermediate % and entry-test %, then computes merit with a
  labelled sample 70/30 formula. It also handles both numbers in one message
  ("inter 90 test 80"), and knows the difference between "calculate my merit"
  and "when does the merit list come out".

## Features

- **13 intents** — greeting, small talk, deadlines, merit, entry test, fees,
  scholarships, programs, documents, hostel, eligibility, campus life, goodbye.
- **English + Roman Urdu** — understands both, replies in English.
- **Multi-turn merit calculator** — sample 70/30 formula, with a plain-language
  verdict (sample guide: 85+ very strong, 70–85 competitive, 50–70 workable).
- **Honest fallback** — "I don't have a confident answer for that yet" instead
  of a made-up answer, plus suggested questions.
- **Confidence shown** — every bot reply shows its detected intent and
  confidence (rule-routed replies show the intent only, no fake confidence).
- **Quick-reply chips, typing indicator, clear-chat** — a real chat UI, no
  external libraries.
- **Input validation** — empty or over-long messages return a clear `400`.
- **No API keys, no build step, works offline** — plain Flask + HTML/CSS/JS.

## Tech stack

- Python 3.10+, Flask
- scikit-learn (TF-IDF + LogisticRegression intent classifier; TF-IDF cosine retrieval)
- pandas, joblib
- Vanilla HTML / CSS / JavaScript frontend

## Model performance (sample data only)

Trained on 209 rows, evaluated on a held-out set of 53 rows
(`train_test_split`, `test_size=0.2`, `random_state=42`, stratified):

| Metric | Value |
| --- | --- |
| Accuracy (held-out) | **0.7736** |
| Macro F1 (held-out) | **0.7679** |

Why is accuracy 0.77 and not 0.99? The training utterances are short templates
("fees kitni hai", "hostel hai"), and several intents share words ("test" appears
in entry-test, merit and eligibility questions), so the classifier genuinely
confuses some phrasings. Real user messages will differ from the templates, so
expect lower accuracy in the wild — that is why the bot has the keyword router
for greetings/goodbyes/merit and a retrieval fallback that answers from the KB
even when the label is uncertain. Six candidate models were compared on the same
split (LogisticRegression C=1/10/100, LinearSVC, MultinomialNB, ComplementNB);
LogisticRegression at C=100 won (tied with LinearSVC, but it gives probabilities
the app needs for confidence). Re-run `train_model.py` to reproduce these
numbers; they will change if the data changes.

## Setup

### Windows (PowerShell + VS Code)

```powershell
cd pakistan-university-admissions-chatbot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python train_model.py
python app.py
```

Then open http://127.0.0.1:5000 in your browser.

### Linux / macOS

```bash
cd pakistan-university-admissions-chatbot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python train_model.py
python app.py
```

Then open http://127.0.0.1:5000 in your browser.

> `train_model.py` must be run once before `app.py`, because it creates
> `model.pkl`. It is gitignored — cloning the repo fresh requires training first.

## API

### `POST /chat`

Request (JSON):

```json
{ "message": "mera merit kitna banega?", "session_id": "optional-uuid" }
```

`session_id` is optional — the bot returns one, and the frontend sends it back so
the multi-turn merit flow remembers your Intermediate %. Response: the reply,
detected intent, confidence (`null` for rule-routed replies), and suggested
follow-up questions. Invalid input returns
`{"success": false, "error": "..."}` with HTTP 400.

### `GET /api/sample-questions`

Example questions to try.

### `GET /api/stats`

Intent list, KB size, model metrics, and the sample merit formula.

## Limitations (read before using)

- Sample/synthetic data — 262 templated utterances and 30 hand-written answers.
- Fees, merit cut-offs and dates in the knowledge base are illustrative samples,
  not official figures. Confirm exact values on the university's official site.
- The bot is not an official university helpline and its answers are general
  information, not admission advice.
- Sessions live in server memory only — restarting the app forgets open
  conversations.
